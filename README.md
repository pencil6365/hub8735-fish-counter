# HUB8735 Ultra 智慧魚缸

目標是使用 HUB-8735_ultra（RTL8735B / JXF37）從上方辨識魚，畫框並顯示當前可見魚數，初期以五尾內的孔雀魚、金魚為主。模型只有 `fish` 一類，不分魚種。

**2026/10/28 狀態：訓練完成、官方轉檔申請已送出，尚無魚模型 `.nb`。串流模式已完整編譯，AI 程式碼已通過語法檢查；尚未完成帶 `.nb` 的 AI 完整編譯、燒錄與現場測試。**

## 從另一台電腦繼續

1. 在本儲存庫的 Releases 下載完整搬機 ZIP；GitHub 自動產生的 Source code ZIP 不含全部工具和資料。
2. 全部解壓到 `C:\Fish`，預留至少 3 GB。
3. 雙擊 `00_START.cmd`，選 1 準備環境。
4. 官方 `.nb` 到手後，選 2 安裝、5 填入自己的 Wi-Fi、3 編譯。
5. 只有明確同意覆寫板上程式時才選 4，依提示輸入 `FLASH` 燒錄。

GitHub 版已將 Wi-Fi 與通知信箱等私人文字設定替換；沒有上傳登入憑證。USB 驅動、序列監控、VLC 及 Python 訓練環境不包含在搬機工具中。

## 驗證限制

模型仍可能漏檢與空缸誤判。俯視斑馬魚保留測試 24 張中 11 張數量一致，不能當成使用者魚缸準確率。三張目標魚圖數對是訓練擬合檢查。UINT8 量化、板上啟動及實際魚缸都還要驗證。

搬機版先啟動 AI 再連 Wi-Fi；無 Wi-Fi 時預期本機推論持續，但無 RTSP，且此行為尚待實板確認。不得宣稱此原型已可靠上線。

套件與資料含第三方授權，詳見完整包中的來源紀錄；此儲存庫不替第三方程式、模型和資料另行授權。
